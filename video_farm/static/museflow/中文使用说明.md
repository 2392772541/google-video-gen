# MuseFlow 0.5.0 简体中文版

## 安装或更新

### 已经从本目录加载过原版
1. 在浏览器扩展管理页找到 26Flow，点击“重新加载”按钮。
2. 刷新已打开的 Muse.ai 页面和插件工作流页面。
3. 点击插件图标，确认显示“26Flow 中文版”或中文工作流界面。

继续使用本目录可以尽量保持原有扩展 ID 和本地工作流数据。建议先导出重要工作流；更换解压目录或重新安装可能改变扩展 ID，从而使用独立的本地存储。

### 首次安装
1. 解压中文版 ZIP 到固定目录（已有本目录时可直接使用，无需再次解压）。
2. 打开 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的目录。
4. 打开 https://muse.ai 并登录，然后点击插件图标打开工作流。

## 新增优化与功能（单模块生成与自定义生图模型）

### 1. 解决修改单个功能导致全部重跑的 Bug
- **单节点运行隔离与缓存保护**：在“生成图片”或“生成视频”节点上点击“▶ 生成图片/视频”时，**仅强制重新生成该目标节点**。其上游依赖项（如相连的参考图片或上一个连续视频片段）若已生成完毕，会自动复用已有素材资产，绝不清空已有结果，也不重复发起请求。
- **智能增量运行（默认模式）**：顶栏“▶ 运行”按钮默认采用智能增量调度。若某个节点已完成生成且提示词、尺寸等未被修改，会自动跳过；仅生成从未运行过或被修改过（包含下游脏依赖）的节点。状态栏会清晰显示“已跳过 X 个未变更项”。
- **全量运行控制**：顶栏新增“↺ 全量运行”按钮，画布空白处右键菜单新增“↺ 全量重新运行”，在需要推倒重跑全部镜头时可随时一键执行。
- **选区运行**：多选（按住 Shift 或 Ctrl 点击）一个或多个生成节点后，右键支持“▶ 运行选中节点”，仅定向重跑选区任务。

### 2. 生图模型可选项化与自定义模型
- **节点下拉选择**：“生成图片”节点的生图模型升级为下拉选择框，预设包含：`Muse.ai (默认)`、`FLUX.1 Schnell`、`FLUX.1 Dev`、`DALL·E 3`、`Stable Diffusion XL`、`Midjourney`。
- **快捷输入自定义模型**：在下拉列表中选择“＋ 自定义模型...”，即可输入自己的模型名称（如 `flux-pro`、`sd-v1.5`、`my-model` 等），输入后立即生效并加入持久化模型库。
- **全局设置专区**：点击顶栏“设置”，在弹出的“生图模型设置”中可统一配置新建节点默认使用的生图模型，以及管理、删除自定义模型。
- **生成请求透传**：选择非默认模型时，系统会在提示词指令中明确附加 `[Model: 模型名]` 并写入生成任务元数据中。

### 3. 解决视频生成失败导致工作流卡死的 Bug（容错隔离与快速熔断）
- **快速失败检测（Fast-Fail）**：`muse-bridge.js` 彻底解决了原本失败时死等 600 秒（10分钟）的卡死问题。当 Muse 停止响应、页面报错或 Stop 按钮消失超过 2.5 秒却未产出视频时，立即中断并返回具体失败原因，不会让插件陷入长时间挂起。
- **节点级故障隔离（Fault-Tolerance）**：单节点生成失败（如提示词触发风控或服务端异常）时，工作流调度器自动隔离异常并标红该节点，**绝不中断整个工作流循环**，后续其它无依赖的独立视频/图片片段将继续正常推进生成。
- **连续性依赖安全跳过**：若下游视频开启了尾帧连续性（Continuity）而前置片段生成失败，下游节点会自动标记为“等待前置片段生成完成”并安全跳过，同时保持工作流继续推进其它独立分镜。
- **状态完全解锁与单独重试**：运行结束后状态必然恢复为 `▶ 运行`，状态栏清晰汇总“成功 X 项，失败 Y 项”。用户修改失败节点的提示词后，可直接点击顶栏“▶ 运行”（仅重跑失败项，已成功项自动跳过），或右键“▶ 运行选中节点”单独重试。

## 中文脚本示例

在“脚本 → 节点”中粘贴下面的内容，再使用弹窗中的创建按钮：

```text
场景 1（0:00–0:06）：清晨山谷
图片提示词：日出时的山谷，柔和金色光线，电影感，16:9
视频提示词：镜头缓缓向前移动，鸟儿飞过山谷，16:9
音频：清脆鸟鸣，轻微风声

场景 2（0:06–0:11）：湖面星光
图片提示词：夜晚的湖面倒映星空，安静自然，16:9
视频提示词：镜头缓慢横移，水面泛起涟漪，16:9
音频：轻柔水声
```

生成器沿用原版的 5、6、8、10 秒选项，脚本中的时长会按原逻辑选择最接近的生成时长；时间线保留脚本编排时长，可手动调整。音频内容会按原版机制附加为 Audio direction 指令，这是正常的请求内容。
