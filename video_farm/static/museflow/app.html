Muse.ai 会话

MuseFlow 直接使用浏览器中已登录的 Muse.ai 标签页。运行工作流时，请保持 Muse 聊天标签页打开。

生图模型与本地 API 设置

选择生图服务引擎，支持直接直连你的本地生图大模型 API（兼容 OpenAI 规范 / SD WebUI），无需经过 Muse 网页端。

使用本地生图模型时，无画风依赖的分镜图片将自动并发并行制作，无需一个个等待；若开启了“参考前序图片画风”，系统会自动等待上一张底图生成完毕作为参考以防走偏。

从分镜脚本创建节点

粘贴包含“场景”“图片提示词”“视频提示词”和可选“音频”的分镜脚本；也兼容原版越南语格式。MuseFlow 会创建并连接各场景，然后按顺序将视频片段加入时间线。
