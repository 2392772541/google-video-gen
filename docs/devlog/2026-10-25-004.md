## 一、需求背景与目标
将 E:/IDM下载/压缩/museflow-demo-2026-10-09/MuseFlow-0.5.0-简体中文版/ 接入视频制作平台，保证可用，非单纯接入而是深度集成已有功能

## 二、现象排查与根因分析
原版 MuseFlow 为 Chrome 浏览器扩展且绑定 muse.ai，Web 环境无法直接运行；视频工坊拥有 Flow/Gemini/Vids 等本地与代理生成能力及素材库，需要实现双引擎调度、Web 原生运行与素材互通

## 三、方案设计与技术决策
1. 挂载 /museflow 路由原生托管 app.html；2. 编写 runtime-adapter.js 提供通用 Chrome API 垫片与 localStorage+8088 磁盘双重持久化；3. 注入视频工坊素材库抽屉与时间线 FFmpeg MP4 高清合成能力；4. 全局 Studio 导航统一集成
