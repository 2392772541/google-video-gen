# 任务目标：全面审核 8088 视频工坊系统、消除冗余、加固风险项并自愈维护

## 核心约束
- 内存保护：全程串行、低并发、避免系统卡死与多进程失控，系统常驻内存严格控制在安全范围。
- 功能安全：保证 8088 视频工坊全功能 100% 可用，不破坏现有数据库真实记录与生产接口。
- 确定性门禁：每一步改动后运行单元测试与端到端实测验证，以客观 exit code 0 和测试日志为准。

## 验收准则 (Acceptance Criteria)
- [x] **AC-001 [系统冗余清理与静态资源收敛]**：安全归档 `video_farm/static/` 暴露的 27 个 `.bak*` 备份文件至 `video_farm_data/archived_baks`；清理根目录及各层悬空 0 字节数据库与杂乱垃圾文件；归拢 20 个单次脚本至 tools/debug_scripts。
- [x] **AC-002 [安全防御与跨域边界加固 (CORP/CORS)]**：修复 `LocalBrowserBoundary` 对 `OPTIONS` 预检返回 405 的问题；为本地合法端口（3000, 23210, 8089, 8317 等）补充标准 CORS 头；解除 `cross-origin-resource-policy: same-origin` 对跨端口媒体加载的拦截；新增 `/api/health` 健康检查端点。
- [x] **AC-003 [工作流孤儿状态自动同步与生命周期自愈]**：修复 `vids_workflows` 状态在所有镜头完成/取消/失败后永久滞留在 `generating` 的缺陷；实现动态状态自愈与状态同步，并在初始化时自动修复历史遗留孤儿工作流。
- [x] **AC-004 [生命周期现代升级与引擎稳定性增强]**：将 FastAPI `@app.on_event` 升级为现代 `lifespan` 机制消除警告；调优 SQLite 并发繁忙超时与连接释放保护。
- [x] **AC-005 [全链路回归验证与零退化审查]**：确保 409 项自动化测试用例与 14 项全链路端到端功能 100% 通过，并交付结构化审查与维护报告。

## 小步推进计划 (Step Breakdown)
1. Step 1: 静态资产与残留垃圾文件清理归档 (AC-001)
2. Step 2: 本地安全边界加固：CORS 预检响应、CORP 策略放行与 /api/health 端点 (AC-002)
3. Step 3: 工作流孤儿状态自愈与动态同步机制实现 (AC-003)
4. Step 4: FastAPI 生命周期升级为 lifespan 与数据库调优 (AC-004)
5. Step 5: 全量自动化测试、端到端 QA 验证与代码质量审查 (AC-005)
